# SmartShot – Project Summary

## Overview
**SmartShot** is an intelligent monitoring system built around a smart shot cup that tracks how much alcohol a user consumes during a drinking session.  
The cup measures each shot, sends the data to a mobile application, and displays real-time consumption statistics.

Our goal is to give users a clear overview of their alcohol intake, support responsible drinking habits, and bring modern technology into social environments.

---

## Key Features
- **Smart Measurement:** Built-in sensors measure each shot poured into the cup.  
- **Real-Time Tracking:** Data is sent instantly to the mobile app via Bluetooth.  
- **Session Overview:** Total volume, number of shots, and drinking history.  
- **Safe-Drinking Insights:** Basic analytics to inform the user about their consumption rate.  
- **Modern Mobile App:** Clean UI, clear graphs, and accessible data.  

---

## Technologies Used
- **Hardware:** Sensors, embedded microcontroller, Bluetooth module  
- **Software:** Firmware for data measurement & transmission  
- **Mobile App:** Real-time BLE-enabled mobile application  
- **Tools:** 3D modeling, prototyping, UX design tools  

---

## System Architecture
The SmartShot system consists of:

### 1. SmartShot Cup (Device)
- Built-in measurement sensor  
- Microcontroller for data processing  
- Bluetooth module for communication  

### 2. Mobile Application
- Receives data from the cup  
- Displays statistics clearly  
- Stores history of drinking sessions  

### 3. Data Flow
Shot poured → device measures → sends via BLE → app displays live data
